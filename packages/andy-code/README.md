# Andy Code

> Tu equipo de desarrollo autonomo con Inteligencia Artificial, directamente en tu editor. Impulsado por Andy Agent Prime y Pantheon Squads.

**Andy Code** integra una suite completa de desarrollo autonomo con inteligencia artificial en Visual Studio Code y Cursor, sincronizada en tiempo real con tu servidor Andy Agent Linux (https://ia.v2nethost.cl:3000).

---

## Caracteristicas Principales

- **Escuadrones Autonomos Pantheon**: Delegacion coordinada en equipos de desarrollo completos (Software Development Team, FullStack Squad, Audit & Fix Squad).
- **Modos Especializados de Trabajo**:
  - **Architect**: Planificacion de arquitectura de proyectos, generacion de especificaciones y diagramas tecnicos.
  - **Code**: Implementacion, refactorizacion y creacion de codigo fuente en cualquier lenguaje.
  - **Debug**: Diagnostico sistematico de problemas, analisis de trazas de error y resolucion de bugs.
  - **Ask**: Explicacion de codigo, arquitectura y conceptos tecnicos sin modificar archivos.
  - **Orchestrator**: Coordinacion estrategica de flujos de trabajo complejos delegando en roles especializados.
- **Editor de Diferencias (Diffs)**: Visualizacion y aprobacion de cambios de codigo linea por linea en tiempo real.
- **Destructive Command Guard (DCG)**: Proteccion de la terminal contra comandos peligrosos o destructivos con aprobacion granular.
- **Soporte Nativo MCP (Model Context Protocol)**: Conexion con servidores y herramientas MCP locales y remotos.
- **Sincronizacion en Tiempo Real**: Lista y sincroniza automaticamente los modelos, agentes personalizados y escuadrones alojados en tu servidor Andy Agent Linux.

---

## Configuracion y Proveedores

Andy Code viene preconfigurado con conexion automatica a tu servidor Andy Agent (https://ia.v2nethost.cl:3000/v1). Ademas, cuenta con la opcion de **Proveedor Personalizado** para ingresar URLs personalizadas (servidores locales Ollama, LM Studio, vLLM o APIs compatibles con OpenAI).
